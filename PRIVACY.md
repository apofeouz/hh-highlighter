# Политика конфиденциальности — HH Visited Highlighter

**Дата обновления:** 02.09.2026  
**Расширение:** HH Visited Highlighter (Chrome Web Store: `bgmokfidjolcodaacpkjaoihldgldkko`)  
**Автор:** apofeouz — https://github.com/apofeouz/hh-highlighter

## Кратко

Расширение **не собирает, не передает и не продает** ваши данные третьим лицам. Вся информация хранится только локально в вашем браузере.

## Какие данные обрабатываются

Расширение работает только на `https://*.hh.ru/*` и использует:

1. **Настройки** в `chrome.storage.sync` — `вкл/выкл`, выбранный цвет подсветки (`#d32f2f` по умолчанию). Синхронизируются между вашими устройствами через Chrome Sync, если он включен.
2. **История просмотров** в `chrome.storage.local` + `localStorage` — `id` вакансии/резюме (`vacancy:123`), `title`, `href`, `ts` (время просмотра). Нужно чтобы подсветить уже посещённые карточки, показать бейдж и список в попапе/`history.html`.

Это подпадает под категории Chrome Web Store **«История веб-поиска»** (список посещённых страниц hh.ru) и **«Содержимое сайтов»** (заголовки вакансий) — но только в локальном хранении.

## Что НЕ собирается

- Имя, email, телефон, адрес, возраст, документы
- Медицинские, финансовые, платежные данные
- Пароли, PIN, токены
- Личная переписка, местоположение, файлы
- Данные вне `hh.ru`

## Передача данных

Нет передачи на внешние серверы, аналитику или третьим лицам.  
Сторонние запросы расширение не делает. Удаленный код (`eval`, внешние `<script>`) не используется.

## Хранение и удаление

Данные хранятся до очистки вами:
- Кнопка **«Очистить всё»** в попапе или на странице `history.html` → удаляет `hh_history` и `localStorage hh-visited:*`
- Удаление расширения → Chrome удаляет его `storage` автоматически
- Бейдж на иконке показывает количество из `hh_history` локально.
